# FDA food recalls

`data/fda-food-recalls-2012-2026.json`: every FDA food recall enforcement report in openFDA, June 2012 through October 2026. 29,505 records, pulled on 25 October 2026.

Source: https://open.fda.gov/apis/food/enforcement/
Field definitions: https://open.fda.gov/apis/food/enforcement/searchable-fields/
